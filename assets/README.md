# assets

Drop a photo here as `profile.jpg` (`.png` and `.jpeg` work too) and the next
Action run redraws the ASCII portrait on the profile card from it, replacing the
placeholder figure that ships in `ascii_art.txt`.

A head-and-shoulders crop with the subject clearly brighter than the background
converts best — the card only gives the portrait 42 columns by 25 rows, and a
full-length shot loses the face at that size.

See [docs/SETUP.md](../docs/SETUP.md) for the conversion flags.
